03 / Decisions worth discussing

Engineering judgment is visible in what did not ship.

FEATURE VALUE / CONTROLLED ABLATIONS

Make every additional join earn its place.

The original representation selected 700 features from 2,508 candidates. Matched source-family removals measured the predictive contribution of the engineering work.

Controlled removalMean stability change
depth2-0.015762
previous applications-0.031440
credit bureau a-0.093813

Predictive removal effects, not causal effects on borrowers. Results use the same five development folds.

PROMOTION / RELIABILITY

A better AUC is not enough.

A 256-feature extension improved pooled AUC but reduced mean stability. It was not promoted. Later studies preserve their own selection and confirmation decisions instead of rewriting the historical release.

Repeatedly explored folds are labeled as development evidence. The repository separates execution success, predictive improvement and release readiness.

04 / Reproducible public layer

Verify without credentials,
cloud spend or training.

The brief reuses the existing credential-free aggregate verifier. Seven pinned source files bind the displayed evidence. The build is deterministic, and an existing bundle is verified rather than overwritten.

git clone https://github.com/alvaromendizabal/home-credit-model-stability.git
cd home-credit-model-stability
python3 scripts/review_portfolio_brief.py
python3 scripts/review_portfolio_brief.py --check

Open artifacts/portfolio-brief/index.html. Python 3.12 and its standard library are sufficient. To check the repository's committed brief, add --output reports/portfolio/brief --check.

What the command establishes

Public input hashes, consistent populations, weekly stability recomputation, controlled ablation deltas and byte-identical HTML, SVG and JSON output. No model deserialization or network requests.

Read the exact reproduction boundary ↗

What it does not establish

Full private-data retraining, independent authentication of the original training run, production lending readiness, financial impact or a fresh out-of-sample result.

05 / Published deliberately

Open engineering. Protected research assets.

Public and inspectable

Historical implementation code, aggregate results, executed notebooks, tests, documented decisions and portable evidence tools. The live stability lab uses synthetic weekly curves and is explicitly not a predictive model.

Not included in this brief

Borrower records, feature matrices, trained model binaries, active feature identities, current ensemble recipes, access credentials and operational transfer bundles.

The public portfolio is a completed research-and-inference case study. Further robustness and production validation are separate work; no paid workload needs to remain active to review the published evidence.
